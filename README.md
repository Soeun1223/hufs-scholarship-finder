# 외대 장학 찾기

받을 자격이 있어도 몰랐던 장학금을 내 조건으로 찾고, 지원 요건을 확인하고, 신청 준비까지 이어가는 한국외대 장학 서비스입니다. 학생이 만든 비공식 프로젝트이며, 최종 지원 자격과 일정은 항상 원문 공고가 기준입니다.

## 기능

| 메뉴 | 하는 일 |
|---|---|
| 나에게 맞는 장학금 | 캠퍼스, 학과, 학기, 평점, 학자금 지원구간, 지역, 해당 사항 중 아는 것만 입력하면 모집 중 공고를 `지원 가능(입력 조건 기준)` / `확인 필요` / `현재 조건과 다름`으로 나눠 마감 임박 순으로 보여줍니다. 입력하지 않은 항목은 자격 미달로 처리하지 않습니다. |
| 공고 상세 | 공고 요건과 내 조건을 항목별로 비교한 표, 마감과 신청 경로, 면접 일정, 금액, 중복 수혜, 정보 출처와 수집일, 원문 링크를 보여줍니다. |
| 관심 장학금 | 관심 장학금을 저장하고, 제출 서류 체크리스트를 체크하거나 직접 추가하고, 마감일과 면접 일정을 캘린더 파일(.ics)로 저장합니다. 날짜가 주 단위로만 나온 면접은 "예정 기간"으로 저장합니다. |
| 모집 중 전체 | 분류(교내, 교외, 국가, 지자체), 캠퍼스, 7일 안에 마감, 상시 모집, 학교 추천 필터로 전체 공고를 봅니다. |
| 마감 달력 | 월별 달력에서 모집 중 공고의 마감일을 한눈에 봅니다. |
| 지난 장학금 | 마감된 공고의 요건을 보고 다음 모집을 준비합니다. |

## 개인정보

- 로그인이 없고 서버도 없습니다. 입력한 조건은 어디로도 전송되지 않고 브라우저 안에서만 비교합니다.
- 조건은 기본으로 저장하지 않습니다. "이 기기에 조건 저장"을 켰을 때만 브라우저(localStorage)에 남고, "내 조건 지우기"로 삭제합니다.
- 관심 목록과 체크리스트는 같은 브라우저에만 저장됩니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 설치할 것이 없습니다.

로컬 서버로 보고 싶다면:

```bash
node scripts/serve.js
```

GitHub Pages로 공개하려면 저장소 Settings → Pages에서 `main` 브랜치의 루트를 선택합니다.

## 공고 데이터

공고는 `data/scholarships.js` 한 파일에 있습니다. 관리자 화면은 없고, 공고 내용을 Claude가 읽어 이 파일을 채우면 사람이 확인하는 방식으로 운영합니다. 항목 설명과 갱신 절차는 [docs/DATA_GUIDE.md](docs/DATA_GUIDE.md)에 있습니다.

현재 데이터는 2026년 11월 6일에 장학(공지) 게시판에서 정리한 27건입니다. 조건이 첨부파일에만 있는 공고는 `source: "첨부"`로 표시되어 있고, 화면에서는 항상 "확인 필요"로 나옵니다.

## 테스트

```bash
node --test
```

성적 경계값, 미입력 항목, 학과 제한, 지역, 마감일, 체크리스트, 캘린더 파일, 데이터 파일 형식을 검증합니다.

## 아직 없는 것

- 공고 자동 수집: 학교 홈페이지의 `robots.txt`가 게시판 경로(`/bbs/*`)의 자동 수집을 막고 있어서 만들지 않았습니다. 자동화하려면 장학팀·정보처와 협의가 필요합니다.
- 서비스 내 관심 현황: 서버가 필요해서 넣지 않았습니다.
- 학과 홈페이지 공고 연결: 데이터의 `routes` 항목은 준비되어 있지만 아직 채운 공고가 없습니다.

## 구조

```
index.html              화면 뼈대
styles.css              스타일 (보라 그라데이션 테마, 라이트/다크)
js/logic.js             조건 비교, 마감 계산, 체크리스트, .ics 생성
js/app.js               화면 그리기와 입력 처리
data/scholarships.js    공고 데이터
test/logic.test.js      테스트
scripts/serve.js        로컬 미리보기 서버
docs/DATA_GUIDE.md      데이터 항목과 갱신 절차
```
