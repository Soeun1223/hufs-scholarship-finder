# 공고 데이터 안내

공고는 `data/scholarships.js`의 `items` 배열에 한 건씩 들어 있습니다. 파일을 고친 뒤 `node --test`를 실행하면 형식 오류를 잡아 줍니다.

## 갱신 절차

1. 장학(공지) 게시판에서 새 공고를 엽니다.
2. 공고 본문(과 첨부파일 내용)을 Claude에게 붙여 넣거나 파일로 주고 "장학봄 데이터에 추가해 줘"라고 요청합니다.
3. Claude가 아래 항목에 맞춰 `data/scholarships.js`에 추가합니다.
4. 사람이 원문과 대조해 확인한 뒤 커밋합니다.

마감된 공고는 지울 필요가 없습니다. 마감일이 지나면 자동으로 "지난 장학금"으로 넘어갑니다.

학교 홈페이지의 `robots.txt`가 게시판 경로의 자동 수집을 막고 있으므로, 프로그램으로 게시판을 긁어 오지 않습니다.

## 채우는 원칙

- 원문에 없는 조건은 추측해서 채우지 않습니다. 제한이 없으면 `null`, 원문에서 확인하지 못했으면 요약에 "원문 확인"이라고 적습니다.
- 조건이 첨부파일에만 있고 아직 읽지 못했으면 `source`를 `"첨부"`로 둡니다. 이 공고는 화면에서 "지원 가능"으로 표시되지 않습니다.
- 구조화할 수 없는 조건(나이, 국적, 이수 학점, 백분위 등)은 `summary`에 문장으로 적습니다.

## 항목

| 항목 | 형식 | 설명 |
|---|---|---|
| `id` | 숫자 | 게시판 글 번호. 원문 링크를 만드는 데 씁니다. |
| `title`, `provider` | 글자 | 장학금 이름, 주는 곳 |
| `cat` | 글자 | `교내`, `교외`, `국가`, `지자체` 등 |
| `campus` | `공통` / `서울` / `글로벌` | 지원할 수 있는 캠퍼스 |
| `deadline` | `YYYY-MM-DD` 또는 `null` | 접수 마감일 |
| `applyStart` | `YYYY-MM-DD` 또는 `null` | 접수 시작일 |
| `rolling` | `true` / `false` | 상시 모집 |
| `lastDeadline` | `YYYY-MM-DD` 또는 `null` | 처음부터 지난 공고로 등록할 때의 마감일 |
| `method` | 글자 | `직접 신청` 또는 `학교 추천` |
| `routes` | 배열 | 신청 경로별 마감. 예: `[{"label": "교내 추천 접수", "deadline": "2026-11-17"}, {"label": "재단 최종 접수", "deadline": null, "note": "재단 안내"}]` |
| `quota` | 숫자 또는 `null` | 선발 인원 |
| `sem` | `[최소, 최대]` 또는 `null` | 재학 학기 범위 (`meta.semBasis` 기준) |
| `gpaMin` | 숫자 또는 `null` | 최소 평점 (4.5 만점) |
| `gpaBasis` | `직전학기` / `전체` / `null` | 평점 기준. 모르면 `null` |
| `incomeMax` | 숫자 또는 `null` | 학자금 지원구간 상한 |
| `lowIncome` | `true` / `false` | 가계곤란 심사가 있지만 구간이 명시되지 않은 경우 |
| `regions` | 배열 또는 `null` | `"시·도 시·군·구"` 형식. 예: `["경상남도 통영시"]` |
| `specialsAny` | 배열 또는 `null` | 하나 이상 해당해야 하는 사항 |
| `deptAny`, `deptCampus` | 배열, 글자 | 학과 제한. `deptCampus`가 있으면 그 캠퍼스에만 적용 |
| `amount`, `dup` | 글자 | 지원 금액, 중복 수혜 |
| `interview` | `{label, start, end}` 또는 `null` | 면접 일정. 주 단위로만 나오면 그 주 전체 |
| `docs` | 배열 | 제출 서류. 체크리스트에 그대로 들어갑니다. |
| `summary` | 글자 | 조건 요약 |
| `source` | `본문` / `첨부` | 조건을 어디서 정리했는지 |
| `collectedAt` | `YYYY-MM-DD` | 수집일 |

`meta.collectedAt`은 화면 오른쪽 위의 "공고 수집일"입니다. 데이터를 갱신하면 같이 바꿉니다.
